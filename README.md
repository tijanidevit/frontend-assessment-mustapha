# Frontend Assessment

## Setup

Requirements:
- Node.js 20+
- npm

Clone the repository:

```bash
git clone https://github.com/tijanidevit/frontend-assessment-mustapha.git
````

- Navigate into the application:

```bash
cd frontend-assessment-mustapha/app
```

- Install dependencies:

```bash
npm install
```

- Start the development server:

```bash
npm run dev
```

- Open the application:

```text
http://localhost:3000
```
